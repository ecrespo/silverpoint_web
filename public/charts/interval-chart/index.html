Example

The chart above, in each framework. Pick a framework once and every example on the site follows it. `axis="date"` reads ISO `YYYY-MM-DD` days in UTC.

Import

Each chart has its own subpath, so a bundle only carries the charts it uses. Every adapter also exports every chart from its barrel.

FrameworkImport
Reactimport { IntervalChart } from '@silverpoint/react/interval-chart';
Vueimport { SpIntervalChart } from '@silverpoint/vue/interval-chart';
Angularimport { SpIntervalChart } from '@silverpoint/angular/interval-chart'; // <sp-interval-chart>
Reflexfrom reflex_silverpoint_react import interval_chart

Events

Pointer and keyboard exploration are built in. The item under the pointer or focus is reported, and a click, Enter or Space selects it. The item is { seriesKey, index, datum, value, point: { x, y } }.
