UI components · Data display

Divider

A rule, optionally captioned. Group: Data display · component 14 of 17, new in silverpoint 0.3.

States

The 2 reference states silverpoint declares for Divider, live on both grounds, with their code. As in upstream's documentation the examples are uncontrolled: the state's value is the default value. Pick a framework once and every example on the site follows it.

plain

tsx
import '@silverpoint/fonts/fonts.css';
import '@silverpoint/grounds/styles.css';
import '@silverpoint/grounds/ui.css';
import { SpDivider } from '@silverpoint/react/ui/divider';

<SpDivider />
vue
<script setup lang="ts">
import '@silverpoint/fonts/fonts.css';
import '@silverpoint/grounds/styles.css';
import '@silverpoint/grounds/ui.css';
import { SpDivider } from '@silverpoint/vue/ui/divider';
</script>

<template>
  <SpDivider />
</template>
ts
// src/styles.css:
//   @import '@silverpoint/fonts/fonts.css';
//   @import '@silverpoint/grounds/styles.css';
//   @import '@silverpoint/grounds/ui.css';

import { Component } from '@angular/core';
import { SpDivider } from '@silverpoint/angular/ui/divider';

@Component({
  selector: 'app-root',
  imports: [SpDivider],
  template: `
    <sp-divider />
  `,
})
export class App {}

Import

Each component has its own subpath under ui/, and every adapter exports them all from ui. Import @silverpoint/grounds/ui.css once, beside styles.css; Reflex adds it for you.

FrameworkImport
Reactimport { SpDivider } from '@silverpoint/react/ui/divider';
Vueimport { SpDivider } from '@silverpoint/vue/ui/divider';
Angularimport { SpDivider } from '@silverpoint/angular/ui/divider'; // <sp-divider>
Reflexfrom reflex_silverpoint_react import sp_divider

Props

The props Divider adds to the ones every UI component takes.

React / AngularVueReflexTypeDescription
orientationorientationorientationLiteral['horizontal', 'vertical']horizontal (default) or vertical.
texttexttextstrA caption set in the rule.
alignalignalignLiteral['start', 'center', 'end']Where the caption sits: start, center (default) or end.

Common props

Every UI component also takes these. Like a chart's, they fall back to the dashboard the component sits in, then to the provider. Read more about the UI components.

React / AngularVueReflexTypeDescription
idididstrThe frame variant and every related id derive from it.
groundgroundgroundLiteral['silverpoint', 'cyanotype'] | str | dict[str, Any]Style ground: "silverpoint" or "cyanotype", or a ground object. Defaults to the dashboard's, then the provider's, or silverpoint.
substratesubstratesubstrateLiteral['cream', 'green', 'blue', 'ochre', 'prussian']Prepared substrate within the ground.
modemodemodeLiteral['ink', 'precision']ink by default; precision disables inking.
seedseedseedstr | intSeed of the frame's hand; overrides id for the frame variant only.
sizesizesizeLiteral['sm', 'md', 'lg']Control size: sm, md (default) or lg.
classNameclass-nameclass_namestrAdded to the component's root element, after its own classes.
