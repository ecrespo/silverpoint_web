Reflex (Python) only

Composed components

New in reflex-silverpoint-react 0.7.0. 20 components built in Reflex on silverpoint's frames and tones: tables, pagination, statistics, collapse panels, and overlays — modal, drawer, popover, tooltip, select, menu and toast — on Radix primitives.

Drawn with silverpoint's own pieces

@silverpoint/grounds/ui.css draws its hand-inked frames, hatched tones and heightening on any element that follows its markup contract. These components are built in Reflex on that contract, so they are drawn with exactly the same pieces as the Sp components. sp_surface and sp_glyph are the building blocks, for components of your own.

Mind this
They are Reflex-only (silverpoint's React, Vue and Angular adapters do not have them) and, unlike the Sp components, they do not read silverpoint_provider: pass ground, substrate, mode and palette explicitly.

sp_table · sort_rows

Card-framed table: small-caps header, tabular figures, hatched striping, sortable headers with aria-sort.

On-call teams
Region
CatalogSouth916
ArchiveNorth723
SearchNorth662
BillingEast581
DeliveryWest440
python
class State(rx.State):
    rows: list[dict] = TEAMS
    sort_key: str = "load"
    sort_order: str = "desc"

    @rx.event
    def sort(self, key: str):
        same = key == self.sort_key and self.sort_order == "asc"
        self.sort_key, self.sort_order = key, "desc" if same else "asc"
        self.rows = sort_rows(TEAMS, self.sort_key, self.sort_order)


sp_table(
    [
        {"key": "team", "title": "Team", "sortable": True},
        {"key": "region", "title": "Region"},
        {"key": "load", "title": "Load %", "align": "end", "sortable": True},
        {"key": "incidents", "title": "Incidents", "align": "end", "sortable": True},
    ],
    State.rows,
    caption="On-call teams",
    sort_key=State.sort_key,
    sort_order=State.sort_order,
    on_sort=State.sort,  # receives the column key
    striped=True,
)

    sp_trigger

    The drawn button of every overlay: the SpButton look on a surface, and it forwards Radix's props (sp_button does not).

    python
    sp_trigger("Default")
sp_trigger("Primary", variant="primary")  # light hatching
sp_trigger("Danger", variant="danger")
sp_trigger("Menu", chevron=True)  # a down chevron after the text

sp_popover(rx.el.p("…"), trigger=sp_trigger("Details", chevron=True))

    Surface props

    Every builder takes ground, substrate, mode, size (sm, md, lg), seed, palette, id, class_name and style. Values and lists (rows, items, options) can be static or state vars. Value components (sp_textarea, sp_input_number, sp_select, sp_pagination) send the new value itself to on_change, never a DOM event. Overlays are controlled with open + on_open_change, or uncontrolled with default_open.
