Palettes

New in reflex-silverpoint-react 0.7.0. Re-colour every chart, UI component, dashboard and composed component with six presets named after drawing media, or a palette of your own, checked against silverpoint's contrast thresholds.

Colour without re-rendering

silverpoint never writes a colour into its drawing: every stroke and fill is painted by CSS through the ground's --sp- custom properties. A palette sets them, so it re-colours a chart, a UI component, a dashboard, a composed component or the timeline without re-rendering it. palette= takes a preset name, a Palette, a dict of fields or a state var holding one.

python
from reflex_silverpoint_react import PALETTES, Palette, bar_chart, check_palette, silverpoint_palette, sp_button

bar_chart(title="Orders", palette="sanguine")  # a preset
sp_button("Save", variant="primary", palette={"ink": "#2C6355"})  # a dict of fields
bar_chart(title="Orders", palette=State.palette)  # a state var holding a dict

MINE = Palette(substrate="#F2E8DC", ink="#8A3A24", ink_secondary="#6A4A3A", text="#4A2216")
assert not check_palette(MINE)  # [] when every field meets its contrast threshold

silverpoint_palette(dashboard(...), sp_card(...), palette="indigo")  # a whole section

python
class Theme(rx.State):
    preset: str = "sanguine"

    @rx.var
    def palette(self) -> dict[str, str]:
        return PALETTES[self.preset].to_dict()

    @rx.event
    def set_preset(self, name: str):
        self.preset = name


sp_segmented(items=[ui_item(name, name) for name in PALETTES], value=Theme.preset, on_change=Theme.set_preset)
silverpoint_palette(dashboard(...), palette=Theme.palette)  # re-colours without re-rendering

Build your own

Unset fields keep the ground's own colour. Pick the five that matter most; the preview reads them as a dict, as a state var would. Then measure the result with check_palette: it returns one message per field below its threshold, and [] when the palette passes (only hex colours can be measured; a palette without substrate is measured against cream, #EDE7DA).

FieldCustom propertyMinimum contrast on the substrate
substrate--sp-substrate— (what the others are measured on)
ink--sp-ink4.5:1

heighten--sp-heightenexempt (always outlined)

focus--sp-ui-focus-color3.0:1

Palette.to_dict(), to_css() and merged(**changes) convert and copy palettes; Palette.from_dict() rejects unknown fields. palette_css(palette) returns the declarations as a style dict, and contrast_ratio(fg, bg) is the WCAG ratio of two hex colours.

Rules

  • Monochrome by design. Tone is built from hatch density, so a chart has two inks — ink for the main series and ink_secondary for the second — never a colour per series.
  • precision mode and the system's high-contrast modes still apply on top of any palette.
  • silverpoint_provider takes no palette (it renders no element): use silverpoint_palette.
  • Overlays (modal, drawer, popover, tooltip, select, menu, toast) render in a portal outside any section: give them palette directly.
Note
Palettes are a Reflex feature of reflex-silverpoint-react 0.7. In React, Vue and Angular, set the same --sp- custom properties in CSS (the Tailwind preset names them as tokens).
