Reflex (Python)

Everything you need to use silverpoint with Reflex (Python): install, quickstart, app-wide configuration, precision mode, interaction, export, server rendering, the UI components and what 0.7 and 0.9 add.

Install

Peersreflex >= 0.10.0 (React 19), Python 3.11+
IntegrationA Reflex custom component wrapping @silverpoint/react 0.9; Reflex installs the npm side for you. Every chart, UI component, composed component, overlay, the timeline and the deck is the npm component, with a snake_case Python API.

About the Reflex component

reflex-silverpoint-react is a Reflex custom component that wraps @silverpoint/react 0.9.1. It exposes all 60 charts, the Dashboard (with linking), the 17 UI components (sp_button, sp_input, sp_tabs…), the provider, both grounds, the interaction events, custom readouts (tooltip_template) and the imperative handle (download_svg, get_svg, get_geometry) as Python, and what silverpoint 0.7 added: palettes, 21 composed components and overlays, and the Knight Lab timeline, and what 0.9 added: Marp slide decks (sp_deck), each the npm component itself behind a Python builder.

reflex-silverpoint-react 0.9.1 requires Reflex 0.10.0 or later (React 19) and Python 3.11 or later.

Props are the React props in snake_case: xKey → x_key, hatchFill → hatch_fill, centerLabel → center_label. Every prop, data included, can be a state var. reflex_silverpoint_react.CHARTS is the whole catalog, with each chart's family and props: this site is built from it.

Note
Accessors are field names (strings). The JavaScript API also takes functions; from Python, shape your rows instead.

Since 0.7: palettes, composed components, timeline

The three additions of silverpoint 0.7. Since reflex-silverpoint-react 0.7.1 they are the @silverpoint/react components themselves, drawn on silverpoint's own frames, tones and custom properties, behind Python builders (the React, Vue and Angular code is on the same pages):

Quickstart

Create a fresh app and install silverpoint:

shell
mkdir my_app && cd my_app
pip install reflex reflex-silverpoint-react
reflex init
reflex run

Then replace the app's entry with:

python
# my_app/my_app.py
import reflex as rx
from reflex_silverpoint_react import line_chart

DATA = [
    {"hour": "00", "hits": 18},
    {"hour": "04", "hits": 11},
    {"hour": "08", "hits": 42},
    {"hour": "12", "hits": 64},
    {"hour": "16", "hits": 57},
    {"hour": "20", "hits": 30},
]


def index() -> rx.Component:
    return rx.box(
        line_chart(data=DATA, x_key="hour", value_key="hits", title="Hits per hour"),
        width="480px",
    )


app = rx.App()
app.add_page(index)

Interaction and a custom readout

python
import reflex as rx
from reflex_silverpoint_react import line_chart, tooltip_template


class State(rx.State):
    active: str = "—"

    @rx.event
    def on_active(self, item: dict | None):
        self.active = "—" if item is None else f"{item['datum']['hour']}: {item['value']}"

    @rx.event
    def on_select(self, item: dict):
        print("selected", item["datum"])


line_chart(
    data=DATA,
    x_key="hour",
    value_key="hits",
    on_active_change=State.on_active,
    on_select=State.on_select,
    tooltip=tooltip_template("{datum.hour} h · {value} hits"),
)

UI components

Since 0.3: 17 interface components from reflex_silverpoint_react, drawn as the charts are. Each one adds its stylesheet for you. A form with a controlled input, a switch, tabs and a submit button:

python
import reflex as rx
from reflex_silverpoint_react import (
    bar_chart, line_chart, sp_button, sp_input, sp_switch, sp_tab_panel, sp_tabs, ui_item,
)


class State(rx.State):
    city: str = "Caracas"
    precision: bool = False
    view: str = "traffic"

    @rx.event
    def set_city(self, value: str):  # on_change gets the value, not an event
        self.city = value

    @rx.event
    def set_precision(self, value: bool):
        self.precision = value

    @rx.event
    def set_view(self, value: str):
        self.view = value

    @rx.event
    def save(self, form: dict):
        print(form)  # {"city": "Caracas", ...}: the native inputs submit under their name


def settings() -> rx.Component:
    mode = rx.cond(State.precision, "precision", "ink")
    return rx.el.form(
        sp_input(label="City", name="city", value=State.city, on_change=State.set_city,
                 invalid=State.city == "", message="Required: pick a city"),
        sp_switch(label="Precision", name="precision", checked=State.precision,
                  on_change=State.set_precision),
        sp_tabs(
            sp_tab_panel(line_chart(title="Traffic", mode=mode), value="traffic"),
            sp_tab_panel(bar_chart(title="Errors", mode=mode), value="errors"),
            items=[ui_item("traffic", "Traffic"), ui_item("errors", "Errors")],
            label="Views", value=State.view, on_change=State.set_view,
        ),
        sp_button("Save", type="submit", variant="primary"),
        on_submit=State.save,
    )

New in 0.9: slide decks

A Marp/Marpit Markdown presentation drawn in silverpoint: sp_deck from reflex_silverpoint_react, with @silverpoint/marp as its engine. Directives move a slide to another ground or to precision, list items are fragments, comments are presenter notes, and a silverpoint fence draws a live chart inside a slide.

This deck is sp_deck, live: click into it and use the arrows, Space or Home/End; list items are revealed a step at a time, and the chart is a silverpoint fence.

1 / 3

Slide 1 of 3

python
from pathlib import Path

import reflex as rx
from reflex_silverpoint_react import sp_deck  # installs @silverpoint/marp as the deck's npm dependency

TALK = Path("assets/decks/talk.md").read_text()  # read when the app compiles


class Deck(rx.State):
    page: int = 1
    total: int = 0

    @rx.event
    def on_page_change(self, page: int, total: int):
        self.page, self.total = page, total

    @rx.event
    def on_ready(self, total: int):
        self.total = total


def talk() -> rx.Component:
    return sp_deck(
        TALK,
        page=Deck.page,  # controlled; or default_page=1
        on_page_change=Deck.on_page_change,  # (page, total)
        on_ready=Deck.on_ready,  # (total,)
        show_notes=True,
        palette="iron_gall",  # a preset's name, either spelling
        id="talk",
    )
