Timeline

New in reflex-silverpoint-react 0.7.0. sp_timeline draws Knight Lab's TimelineJS in silverpoint: a skin on the ground's colours and type, and the ground's own hand-inked frames and tone tiles on its markers, eras and buttons.

Install

sp_timeline wraps reflex-knightlab-timeline, an optional extra:

shell
pip install "reflex-silverpoint-react[timeline]"

timeline_available() tells you whether it is installed; without it, sp_timeline raises an ImportError that says how to add it.

In your code

python
from reflex_silverpoint_react import sp_timeline

DATA = {
    "title": {"text": {"headline": "From silverpoint to silverpoint"}},
    "events": [
        {"start_date": {"year": 1484}, "text": {"headline": "Dürer at thirteen", "text": "…"}},
        {"start_date": {"year": 1842}, "text": {"headline": "The cyanotype", "text": "…"}},
    ],
    "eras": [
        {"start_date": {"year": 1400}, "end_date": {"year": 1600}, "text": {"headline": "Metalpoint"}},
    ],
}

sp_timeline(
    DATA,  # TimelineJS data (or a TimelineData of reflex-knightlab-timeline)
    height=560,
    ground="silverpoint",
    substrate="cream",
    mode="ink",
    palette="sepia",
    inked_frames=True,  # the ground's hand-drawn frames and tone tiles
    on_change=State.on_slide,  # the unique_id of the slide shown
)

Two layers: the skin and the hand

  • The skin replaces TimelineJS's colours, type and rules with the ground's --sp- properties: the substrate, the inks, EB Garamond, hairline rules, eras hatched by density, the current marker heightened.
  • The hand reads the ground's own frame and tone masks from hidden probes and lays them on the markers, eras and menubar, so they are drawn with the same pieces as the Sp components. inked_frames=False keeps the skin only; precision, cyanotype and forced colours fall back to exact rules by themselves.

Props and events

PropDefault
data—TimelineJS data (title, events, eras, scale), a TimelineData, or a state var.
options{}TimelineJS options; font and theme are ignored (the skin sets both).
height600Height of the whole timeline (px or a CSS length).
inked_framesTrueLays the ground's hand-drawn frames and tone tiles.
cardTrueFrames the whole timeline as a card.
ground, substrate, mode, palette, seed—The surface props.
on_change—The unique_id of the slide shown.
on_loaded—TimelineJS's loaded payload.
on_nav_next, on_nav_previous, on_zoom_in, on_zoom_out, on_back_to_start—The timeline's navigation.
Note
TimelineJS requests its icon font from a relative path (/css/icons/tl-icons.*). Where that path answers with HTML, the browser logs font-decoding warnings and the buttons lose their icons. Copy tl-icons.woff2, .woff and .ttf from @knight-lab/timelinejs/dist/css/icons into your app's assets/css/icons/, as this site does. For a light list of events, use sp_timeline_list.
