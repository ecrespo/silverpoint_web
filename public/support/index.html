Report a bug

silverpoint's issues live on GitHub. A good report names the package and version, the framework, the chart and a minimal reproduction; the links below open a form pre-filled with those questions.

Where to report

A bug in a chart or an adapterReact, Vue or Angular packages, the grounds, the core.ecrespo/silverpoint →A bug in the Reflex componentreflex-silverpoint-react: Python props, events, the dashboard wrapper.ecrespo/reflex-silverpoint-react →A feature requestA new chart, a new ground, a new prop.ecrespo/silverpoint →A problem with this siteA wrong example, a broken link, a missing page.ecrespo/silverpoint_web →

Before you open one

  1. Check you are on the latest version (v0.2.0) and that every @silverpoint package has the same version.
  2. Search the open and closed issues.
  3. Try mode="precision" and the default ground: it tells a drawing problem from a data problem.
  4. Read the console: silverpoint's development warnings carry a code (SP001…SP016) that says what it did.
  5. Reduce it to the smallest code that shows it: one chart, a few rows of data.
