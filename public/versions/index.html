v0.8.0latest

2026-10-21

Agent access: @silverpoint/mcp, an MCP server that tells agents what silverpoint holds, the agent catalog, the silverpoint skill and a Claude Code plugin.

  • A new package, @silverpoint/mcp: a Model Context Protocol server over stdio (npx @silverpoint/mcp) and stateless Streamable HTTP, hosted read-only at silverpointweb.vercel.app/mcp. See Use with AI (/docs/ai).
  • Eleven tools: get_version, list_charts, get_chart, list_components, get_component, recommend_chart, generate_code (React, Vue, Angular and Reflex), search_catalog, validate_props, render_chart (the canonical SVG) and check_palette; the catalog, each chart and component, the diagnostics and the skill's guides as resources; the choose-chart and build-dashboard prompts.
  • The agent catalog, agent-catalog.json, generated from the published types: the 60 charts and 38 UI components with their names, imports and props in the four frameworks, the grounds, palettes, timeline and the 25 diagnostics. This site publishes it at /agent-catalog.json, with /llms.txt and /llms-full.txt.
  • The silverpoint skill (skills/silverpoint/) and a Claude Code plugin that installs it with the hosted server: /plugin marketplace add ecrespo/silverpoint, then /plugin install silverpoint@silverpoint.
  • No change to the API of @silverpoint/react, vue, angular, core, grounds or fonts, nor to any render.

v0.7.0

2026-10-20

Palettes, 21 composed and overlay components (38 UI components in all) and the Knight Lab timeline, in React, Vue and Angular.

  • Palettes on a new subpath, @silverpoint/core/palettes: six presets verified for WCAG contrast (silverpoint, sanguine, sepia, ironGall, verdigris, indigo), checkPalette, contrastRatio, PALETTE_PROPERTIES and nestProvider. palette on every chart, UI component, dashboard and provider; a nested provider or a prop overrides it field by field.
  • Composed components (14): SpSurface and SpGlyph, the building blocks, and SpTable, SpPagination, SpBreadcrumb, SpAvatar (+ SpAvatarGroup), SpStatistic, SpDescriptions, SpTimelineList, SpCollapse (+ SpCollapseItem), SpEmpty, SpResult, SpTextarea and SpInputNumber.
  • Overlays (7) on the platform's <dialog> and Popover API: SpModal, SpDrawer, SpPopover, SpTooltip, SpSelect, SpDropdownMenu and SpToast (in an SpToaster), each opened by a trigger you write; open + onOpenChange, v-model:open or [(open)].
  • SpTimeline on @silverpoint/<react|vue|angular>/timeline: Knight Lab TimelineJS in the ground's hand, with @knight-lab/timelinejs ^3.9.13 an optional peer and a fallback when it cannot load.
  • Two stylesheets beside styles.css: ui.css now draws all 38 UI components, and timeline.css skins TimelineJS (eras get a strip of their own below the axis labels).
  • UI_COMPONENTS gains 21 rows with a family (ui, composed, overlay); UI_DEMOS gains 35 states; @silverpoint/core/timeline and TIMELINE_DEMO. Diagnostics SP023, SP024 and SP025.
  • A link's href (SpButton, SpBreadcrumb) keeps only relative URLs and http, https, mailto and tel; a headingLevel outside 2..6 draws h3. Both warn SP017.
  • No change to the rendered output of the 60 charts.

v0.6.0

2026-10-10

The second catalog: 27 new charts (60 in all) for distributions, comparisons, hierarchies, fields and networks, with drill-down.

  • Distributions & comparisons (14): HistogramChart, EcdfChart, BoxPlotChart, ViolinChart, RidgelineChart, BeeswarmChart, LollipopChart, DumbbellChart, SlopeChart, BumpChart, ErrorBarChart, IntervalChart, DivergingBarChart and ConnectedScatterChart.
  • Hierarchies & dimensions (8): WaffleChart, MarimekkoChart, SquarifiedTreemap, SunburstChart, TreeChart, ParallelCoordinatesChart, PolarLineChart and PolarScatterChart.
  • Fields & networks (5): DensityBinChart, ContourChart, DelaunayChart, VectorFieldChart and NetworkChart (with the NetworkNode type).
  • Statistics derived in the core: Freedman–Diaconis bins, type-7 quartiles, Tukey whiskers, Epanechnikov densities, a deterministic beeswarm packing, ranks for the bump chart. Each chart has a derived data table and one heightened mark.
  • Owned layouts and engines: stratify, squarify (Bruls et al.), partition, the Buchheim tidy tree, marching squares, Bowyer–Watson with exact predicates and a seeded Fruchterman–Reingold force layout.
  • Controlled drill-down on SquarifiedTreemap and SunburstChart: rootId in, onRootChange / @root-change / (rootChange) out. The chart keeps no root of its own, so a server render is the client's.
  • Hierarchy charts walk as a WAI-ARIA tree by keyboard and announce each node's path, value and share.
  • RidgelineChart requires groupKey, DivergingBarChart levels and ParallelCoordinatesChart dimensions.
  • Recipes on a new subpath, @silverpoint/core/catalog; diagnostics SP020 (invalid hierarchy), SP021 (invalid statistic parameter) and SP022 (group too small).
  • No change to the rendered output of the first 33 charts; each one-chart build stays within 0.1 KB.
  • There is no 0.4 or 0.5 on npm: the packages went from 0.3.0 straight to 0.6.0.

v0.3.0

2026-09-30

17 UI components drawn as the charts are: buttons, inputs, tabs, cards, alerts and more.

  • 17 Sp-prefixed UI components in React, Vue and Angular (ui/<name> subpaths): Button; Input, Checkbox, RadioGroup, Switch, Slider, Rate, Segmented; Tabs with TabPanel, Steps; Card, Tag, Badge, Divider; Progress, Alert, Skeleton.
  • Hand-drawn frames by each ground's own inker: tone as hatching on silverpoint, as the weight of an exact white line on cyanotype. precision mode switches the inking off, as on the charts.
  • A native control underneath every one (<button>, <input>, a <fieldset> of radios): forms submit natively, and the composites follow the WAI-ARIA keyboard patterns, with RTL arrows.
  • Controlled or uncontrolled values: value/onChange or defaultValue in React, v-model in Vue, ControlValueAccessors in Angular.
  • A new opt-in stylesheet, @silverpoint/grounds/ui.css, beside styles.css.
  • React Server Component entry points for Card, Divider, Steps, Tag, Badge, Progress, Alert and Skeleton.
  • UI_COMPONENTS (17 components, 45 states) on @silverpoint/core/ui and UI_DEMOS on @silverpoint/core/ui-demos.
  • No change to the rendered output of any chart.

v0.2.0

2026-09-26

The Dashboard composition, linked charts, the cyanotype ground and a Tailwind preset.

  • Dashboard and DashboardCell: a titled, responsive grid laid out by the core from plain data (columns, spans and row height per breakpoint), identical in React, Vue and Angular and server-renderable.
  • Linked dashboards: link on a datum field (e.g. hour) and every chart marks the same item; onLinkChange / @link-change / (linkChange) report it.
  • A second ground, cyanotype: a white line on Prussian blue where tone is the weight of the line. Nothing is hatched.
  • Reference dashboards (kpi-strip, ops, mixed-spans) on @silverpoint/core/dashboard-demos.
  • Demo datasets now honour every view prop; VolvelleChart's indexRing / indexValue turn the demo.
  • New package @silverpoint/tailwind: a preset naming the --sp- variables as Tailwind tokens.
  • Angular example app server-rendered with @angular/ssr.

v0.1.0

2026-09-25

First public release: 33 charts for React, Vue and Angular on the silverpoint ground.

  • 33 charts in six families, one shared framework-free engine (@silverpoint/core).
  • Adapters for React 18.2+/19 (with RSC server entry points), Vue 3.5 and Angular 21-22.
  • The silverpoint ground with four substrates (cream, green, blue, ochre); ink and precision modes.
  • Accessible by construction: names, descriptions, hidden data tables, keyboard navigation.

reflex-silverpoint-react 0.8.0latest

2026-10-21 · wraps @silverpoint/react 0.8.0

Wraps @silverpoint/react 0.8.0, and brings agent access to Reflex: the reflex-silverpoint skill, its catalog and a Claude Code plugin.

  • SILVERPOINT_VERSION is 0.8.0 and every npm dependency is pinned to it; the Python builders are unchanged.
  • The reflex-silverpoint skill (skills/reflex-silverpoint/): builders, snake_case props, State patterns and events, the provider and palettes, composed components and overlays, the dashboard and the timeline. Every Python example in it is imported and rendered in CI.
  • A Claude Code plugin with the skill and the hosted silverpoint MCP server: /plugin marketplace add ecrespo/reflex-silverpoint-react, then /plugin install reflex-silverpoint@reflex-silverpoint.
  • reflex-catalog.json (scripts/export_catalog.py): each builder's snake_case props and their JS names, joined into silverpoint's agent catalog; attached to every GitHub release.
  • CHARTS documents on_root_change for squarified_treemap and sunburst_chart.

reflex-silverpoint-react 0.7.1

2026-10-20 · wraps @silverpoint/react 0.7.0

Wraps @silverpoint/react 0.7.0: the palettes, composed components, overlays and timeline are now the npm components, with the same Python builders.

  • Palettes are the npm palette prop, merged element → dashboard → provider field by field; check_palette() measures the core's PALETTE_PAIRS, the focus ring included.
  • The composed components (sp_table, sp_pagination, sp_breadcrumb, sp_avatar, sp_statistic, …) and sp_surface and sp_glyph are the npm components, and read silverpoint_provider.
  • Overlays (sp_modal, sp_drawer, sp_popover, sp_tooltip, sp_select, sp_dropdown_menu, sp_toast in an sp_toaster) are the npm components on <dialog> and the Popover API, in place of Radix: they render in place.
  • sp_trigger is a native button drawn by the core that keeps the ARIA an overlay clones onto it.
  • sp_timeline is the npm SpTimeline; @knight-lab/timelinejs 3.9.13 comes with it, so the [timeline] extra is empty.
  • New arguments in the npm names (side="start"/"end", position="bottom-end", extent=, offset=); the old ones still work, deprecated.

reflex-silverpoint-react 0.7.0

2026-10-18 · wraps @silverpoint/react 0.6.0

Reflex-only additions: palettes, 20 composed components and the Knight Lab timeline, on Reflex 0.10.

  • Reflex 0.10.0, and therefore Python 3.11 or later (Python 3.10 is no longer supported).
  • Palettes: palette= on every chart, UI component, dashboard and composed component; silverpoint_palette(...) for a whole section; six presets named after drawing media (silverpoint, sanguine, sepia, iron_gall, verdigris, indigo) and check_palette() against the contrast thresholds of the data model.
  • Composed components, level A (native markup): sp_table (+ sort_rows), sp_pagination, sp_breadcrumb, sp_avatar (+ sp_avatar_group), sp_statistic, sp_descriptions, sp_timeline_list, sp_collapse (+ sp_collapse_item), sp_empty, sp_result, sp_textarea and sp_input_number.
  • Composed components, level B (overlays on Radix primitives): sp_modal, sp_drawer, sp_popover, sp_tooltip, sp_select, sp_dropdown_menu and sp_toast (+ sp_toaster), with sp_trigger as their drawn button.
  • sp_timeline: Knight Lab TimelineJS drawn in silverpoint, a skin on the ground's colours and type plus the ground's own hand-inked frames. Optional extra: reflex-silverpoint-react[timeline].
  • sp_surface and sp_glyph: the building blocks, for components of your own.
  • Still wraps @silverpoint/react 0.6.0: no change to the 60 charts or the 17 UI components.
  • silverpoint 0.7.0 then shipped the same three additions in React, Vue and Angular; the Reflex versions keep their own API (snake_case, overlays on Radix).

Upgrading

The line is on 0.x: a minor release (0.1 → 0.2) may change behaviour, and a change to the rendered SVG is never a patch. Read the entry above before upgrading, and update every @silverpoint package together.
