Outside React, Vue, Angular and Reflex, `@silverpoint/embed@{version}` draws any chart from one JSON spec, `{ "chart": "<slug>", "data": [...], "props": {...} }`, with optional `width`, `height`, `ground`, `substrate`, `mode` and `palette`. `validateSpec` says why a spec cannot render; `renderToSVG` and `renderToHTML` run on a server with no DOM. In a plain HTML page, the standalone file `silverpoint-embed.js` (or `silverpoint-embed.full.js`, with EB Garamond inlined), served by the page itself and pinned with the package's `integrity.json`, defines a `<silverpoint-chart>` element that holds the spec in a `<script type="application/json">` child; `mount(target, spec, options)` drives a chart from code. `specFromTable` from `@silverpoint/embed/hosts` binds a table's columns to a chart's roles for BI tools. The MCP tool `generate_code` writes the page with `framework: "html"`. Guide: {site}/docs/embed
